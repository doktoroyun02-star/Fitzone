FITZONE APK

Bu proje Kivy + Plyer ile Android APK derlemek icindir.

EN KOLAY YOL: GitHub Actions
1) GitHub'da yeni bir repository ac.
2) Bu klasordeki dosyalari repository'ye yukle.
3) Actions sekmesine gir.
4) Build Fitzone APK workflow'unu calistir.
5) Islem bitince Actions calistirmasindaki Artifacts bolumunden Fitzone-APK dosyasini indir.
6) ZIP'ten APK'yi cikartip telefona kur.

Yerel Linux/WSL ile:
buildozer android debug

Cikti genellikle bin/ klasorune yazilir.
